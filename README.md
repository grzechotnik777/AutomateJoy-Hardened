# AutomateJoy

**One-click n8n installer for Windows & macOS**

AutomateJoy lets you run n8n locally with a single click. No Docker, no Node.js, no configuration needed.

## Download

Choose your platform:

### Windows
- [AutomateJoy-Setup-1.0.2-win-x64.exe](https://github.com/newcl/AutomateJoy-Release/releases/latest)

### macOS
- [AutomateJoy-1.0.2-mac-arm64.dmg](https://github.com/newcl/AutomateJoy-Release/releases/latest) (Apple Silicon)
- [AutomateJoy-1.0.0-mac-x64.dmg](https://github.com/newcl/AutomateJoy-Release/releases/latest) (Intel)

## Features

✨ **One-Click Installation** - Install and run n8n in seconds  
🔒 **Local First** - Your data stays on your machine  
💻 **Cross-Platform** - Works on Windows and macOS  
🚀 **No Dependencies** - Everything bundled, nothing to install  
☁️ **Cloud Ready** - Start local, upgrade to n8n Cloud when ready

## Quick Start

1. Download the installer for your platform
2. Run the installer
3. Open your browser to http://localhost:5678
4. Start building workflows!

## What is n8n?

n8n is a powerful workflow automation tool that lets you connect apps and automate tasks without code.
